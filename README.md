# Messenger Backend

A modular, high-performance messaging backend API built with Python, FastAPI, and raw SQL via `asyncpg`. Designed around Domain-Driven Design (DDD) principles to power real-time direct messaging, group chats, and social graph management.

---

## Technologies Used

* **Framework:** [FastAPI](https://fastapi.tiangolo.com/) (Async ASGI)
* **Database Driver:** [asyncpg](https://github.com/MagicStack/asyncpg) (Raw SQL execution with connection pooling)
* **Data Validation:** [Pydantic v2](https://docs.pydantic.dev/)
* **Database:** PostgreSQL 16
* **Package Management:** [uv](https://github.com/astral-sh/uv)
* **Testing:** Pytest
* **Task Runner:** [just](https://github.com/casey/just)
* **Containerization:** Docker & Docker Compose
